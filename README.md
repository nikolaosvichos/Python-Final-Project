# Python-Final-Project
Replication code and data for a sharp regression discontinuity design (RDD) estimating the causal effect of first-time voting eligibility during the 2016 U.S. presidential election on long-term support for liberal democratic norms. Using the 2020 ANES and an age-based eligibility cutoff, the study compares Americans whose first eligible presidential election was 2012 (Obama–Romney) to those who first voted in 2016 (Trump–Clinton). The outcome is a seven-item Liberalism Index constructed via principal axis factor analysis. Models are estimated with `rdrobust` in Python across five subgroups (full sample, partisans, independents, Democrats, Republicans), with and without controls, and subjected to bandwidth sensitivity, placebo cutoff, and polynomial degree robustness checks.
